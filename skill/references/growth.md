# 增长、变现与 GTM（Growth, Monetization, Go-to-Market）

## 1. 增长的前提

**先 PMF 后增长。** 留存曲线不平就砸钱获客 = 给漏桶加水。判断可以开始做增长的信号：留存曲线变平、核心人群 NPS/推荐意愿健康、单位经济模型跑通（LTV > CAC 有望）。

## 2. 增长循环（Growth Loops）优于漏斗

漏斗是线性消耗（投入→产出，停止投入即停止），循环是复利（产出回流为投入）。设计产品时先问：**我们的增长循环是什么？**

四类经典循环：

1. **病毒循环**：用户使用 → 产生邀请/暴露 → 新用户加入 → 更多邀请。变体：协作类产品的"使用即邀请"（文档分享、会议链接）最强，因为邀请是完成 job 的必经动作而非附加动作。
2. **内容循环**：用户创造内容 → 内容被搜索/推荐分发 → 带来新用户 → 创造更多内容（小红书、知乎、YouTube）。
3. **付费循环**：收入 → 再投放 → 新用户 → 收入。前提是 CAC 回收期短于现金流承受力。
4. **销售循环**（B 端）：客户成功 → 案例与转介绍 → 新客户。

**病毒系数 K = 人均发出邀请数 × 邀请转化率**。K>1 极罕见；K=0.5 也很有价值（获客成本减半）。优化顺序：先提高邀请动作的自然性（嵌入 job），再优化转化页。

## 3. 激活与 Onboarding

- 新用户首会话是留存杠杆最大的一段。目标：**最短路径到达价值时刻（Time to Value）**，而不是介绍完所有功能。
- 砍注册前摩擦：能后置的信息收集全部后置（先体验后注册是默认答案，除非法规或成本不允许）。
- Onboarding 设计原则：做中学（引导完成一次真实 job）优于看中学（功能导览浮层，完读率通常 <20%）。
- 空状态是设计重点：新用户看到的第一屏永远是空的，用模板/示例数据/一键导入把空状态变成起跑器。

## 4. 定价（Pricing）

定价是杠杆最大又最被 PM 忽视的技能。核心原则：**按价值定价，不按成本定价**。

- **三种定价基准**：成本加成（下限参考）、竞争对标（市场锚）、价值定价（正解：为客户创造的可量化价值 × 10-30% 作为定价区间）。
- **价值度量（value metric）选择**：按什么计费（席位/用量/结果）。好的价值度量随客户获得的价值同步增长（例如按发送量计费的邮件服务），错误的度量会惩罚使用（按登录次数收费抑制活跃）。
- **分层设计（Good-Better-Best）**：3 档最常见；中间档承接主力（锚定效应下约 60% 选中间）；最高档的存在意义有一半是让中间档显得划算。区分维度用"功能 + 用量 + 服务"组合，警惕把留存关键功能放进低档导致没人升级。
- **免费策略选择**：Freemium（免费版本身有完整价值，靠量转化，适合自传播强的产品）vs 免费试用（全功能限时，适合价值需要体验才能感知的产品）vs 免费额度（用量型产品默认解）。
- **提价纪律**：SaaS 每 12-18 个月应审视一次价格；老客户 grandfather（保留旧价）一段时间换口碑。多数团队的问题是定价过低且多年不敢动。
- **支付意愿调研**：Van Westendorp 四问（太贵不考虑/有点贵/划算/便宜到怀疑质量）快速找到可接受价格带。

## 5. GTM（Go-to-Market）

**GTM 动作模式由客单价决定（B 端）：**

- 年客单 < $5k：自助式（PLG，产品即销售）
- $5k-50k：内销团队（inside sales）+ PLG 辅助
- > $50k：外勤销售、POC、方案定制

错配是烧钱主因：低客单配销售团队必亏，高客单纯靠自助转化不动。

**PLG（产品驱动增长）要点：** 免费入口 + 产品内价值展示 + 用量/协作自然扩张 + 到达阈值触发销售跟进（PQL：产品合格线索，比 MQL 转化率高 3-5 倍）。

**发布分级打法：** 不是所有发布都值得开发布会。分级：Tier 1（全渠道 campaign + 发布会 + KOL）每年 1-2 次；Tier 2（官方博客 + 邮件 + 应用内公告）每季度若干；Tier 3（changelog + 应用内提示）常态。每个 Tier 预设资源包和检查清单。

**launch ≠ GTM。** 发布是一天，GTM 是贯穿"定位 → 打包 → 定价 → 渠道 → 销售赋能 → 客户成功"的系统。发布后 30/60/90 天的采纳率追踪与迭代才是大头。

## 6. 变现与商业模式速查

常见模式与 PM 关键指标：订阅（NDR、流失率）、交易抽成（take rate、GMV 健康度）、广告（库存、填充率、eCPM，以及"广告负荷 vs 体验"的护栏）、增值服务/道具（付费渗透率、ARPPU）、开放平台（生态分成）。

**广告与体验的平衡纪律**：广告负荷提升的收入是即期的，体验损伤反映在留存上是滞后 3-6 个月的——短期 A/B 测不出真实代价，要用长周期 holdout 组（保留 1-5% 用户长期不加载新广告策略作为对照）。
