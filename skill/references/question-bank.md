# PM 面试题库（Question Bank）

**适用范围：仅在 PM 求职面试准备场景使用**，配合 interview-coach.md（出题时从本题库按岗位类型抽题）与 pm-job-interview-prep.md（每类题的答题结构）。

题目整理自公开面经与题集（人人都是产品经理、牛客网、Exponent 等），非任何公司内部题库。模拟面试出题原则：**优先把通用题型套到候选人自己的经历和目标公司的产品上**（真实面试官就是这么出题的），题库原题用于冷启动和查漏。

## 一、产品设计题（答题结构见 prep 第 1 节 / discovery.md 第 7 节）

**从零设计类：**
- 如何从 0 到 1 设计一款产品？（通用流程题）
- 如果让你设计一款社交/音乐/金融/读书类产品，你会怎么做？
- 给老年人设计一个购物体验 / Design a shopping experience for elderly users
- 给盲人设计一款打车软件（约束型设计，考人群同理心）

**改进优化类：**
- 你最常用的一款 App，如果你是它的 PM，未来发展方向是什么？
- 如何改进 Instagram Stories / 微信朋友圈 / 抖音评论区？
- How would you improve Google Calendar for remote teams?（带明确人群约束的改进题）
- How would you improve Spotify as a podcast app?（带业务方向约束的改进题）
- 如何给一个产品做一次改版发布？（考流程 + 灰度意识）

**观点认知类：**
- 你最喜欢的产品是什么，为什么？（最高频开场题——考判断标准，不是考产品知识）
- 最近在用什么 App？推荐一款给我（同上，但更即兴）
- 谈谈微信公众号、小程序、App 之间的区别（生态理解题）
- 用户为什么选择你的产品而不是竞品？（竞争认知题）

## 二、指标与数据分析题（答题结构见 prep 第 3 节 / metrics.md）

**异动分析类：**
- 某 App 日活下降 20%，分析原因并说明思路（国内最高频数据题）
- Daily active users have gone down. How would you find the root cause?
- YouTube 评论量上升但观看时长下降，你怎么办？（指标矛盾题，考权衡）

**指标设计类：**
- 你怎么衡量 Instagram Reels / 微信视频号 的成功？
- Netflix / 阿里巴巴 的 PM 应该关注什么指标？
- Airbnb 的北极星指标应该是什么？（考北极星的选取标准）
- 如果你是 eBay 的 PM，你会设什么目标？

**实验设计类：**
- 为 Google 地图设计一个 A/B 测试来改进它
- 你是怎么做数据分析的？（开放流程题，用异动排查链 + 指标体系作答）

**体系搭建类（社招 3 年+ 高频，用 data-system.md 作答）：**
- 如何为一个新业务从 0 搭建数据指标体系？
- 如何为你的团队/老板设计一个数据看板？
- 你们的埋点是怎么规划的？口径不一致怎么治理？
- 给这个功能算一笔账：值不值得做？（单位经济/收入拆解题）

## 三、估算题（答题结构见 prep 第 4 节）

- 估算武汉出租车司机的月收入（国内经典）
- Estimate the number of Uber drivers in San Francisco
- 估算 YouTube 每天被观看的视频数量
- 估算某高校 1000 名研究生需要的总网络带宽
- 估算纽约每年线上果蔬销售额

## 四、策略题（答题结构见 strategy.md；高阶推演见 strategy-advanced.md；商业测算见 business-analysis.md）

- 三星应该做游戏主机吗？（进入决策题：用机会评估六问）
- 如何提升 YouTube / Microsoft Edge 的用户量？（增长策略题）
- YouTube 最大的威胁是什么？（竞争威胁题：五力 + 替代品视角）
- 如果出现一个和 Gmail 竞争的产品，你如何应对？
- Uber Eats 应该独立成一个 App 还是留在 Uber 主 App 里？（架构取舍题）
- 如何减少社交媒体上的假新闻？（社会型难题：考多方权衡与护栏思维）
- 谈谈你对 [当前热点技术] 的看法？最近关注的行业动态？（考信息面与独立判断）

**商分/高阶策略类（高级岗与战略岗）：**
- 你怎么快速了解一个陌生行业？（business-analysis.md 第 1 节 SOP 作答，提"招股书 + 利润池 + 业内访谈"三板斧）
- 这个行业里谁最挣钱？为什么是他们？（利润池 + 关键约束资源）
- 竞对突然降价/免费，你怎么应对？（三步棋推演 + 不对称回应）
- 我们该不该做开放平台/该不该自营？（利润池分层 + 生态信任成本）
- 双边平台怎么冷启动？补贴该怎么设计？（strategy-advanced.md 第 1 节）
- 评估一下这个新业务提案值不值得投？（商业模式六关 + 红旗清单）

## 五、工作方法题（国内社招高频，答题用对应工作文件）

- 需求来源有哪些？如何划分优先级？（prioritization.md）
- 一份 PRD 应该包含什么？（execution.md 第 1 节）
- 同时面对几个需求但精力有限，如何安排？（prioritization.md）
- 需求要延期了，你怎么处理？（execution.md 第 6 节 + 干系人沟通）
- 如何挖掘用户的真实诉求？如何把用户需求转化为产品需求？（discovery.md）
- 用户画像怎么做？（discovery.md 第 4 节）
- 你是怎么做用户调研的？（discovery.md 第 2 节）
- 如何防止产品失败？（验证阶梯 + PMF 信号）
- 新产品如何获取种子用户？如何提升月活？（growth.md）
- 商业产品经理和用户产品经理的区别？
- 你有自己做产品的方法论吗？简单介绍一下（考体系化程度——用"问题分类→选工具"的元方法作答优于报一串框架名）

## 六、协作与冲突题（答题结构见 prep 第 5 节 STAR + stakeholders-career.md）

- 技术说你的需求做不了，你怎么办？（牛客十问经典）
- 和开发发生矛盾怎么解决？
- 你的方案和老板的方案冲突，怎么处理？
- 客户/业务方临时加需求，怎么办？
- 法务对你的功能提出合规担忧，你怎么推进？（Meta 风格）
- 你是如何跨部门协作的？
- Tell me about a time you handled a difficult stakeholder
- 讲一个你做了短期牺牲换长期收益的决定

## 七、经历与行为题（素材准备见 experience-mining.md）

- 自我介绍（准备 1 分钟 / 3 分钟两版）
- 最成功/最有成就感的项目是哪个？为什么？
- 讲一个失败的项目 / 你的产品失败的经历
- 项目里挑一个亮点功能，讲背景和你的思考过程
- 项目中最大的挑战是什么？怎么解决的？
- 如果重来一次这个项目，你会怎么改进？（复盘题，牛客十问压轴）
- 项目延期怎么解决的？怎么避免？
- 讲一个让你难受/沮丧的产品决策
- 说一下一个产品从 0 到上线的完整过程（流程叙事题）

## 八、职业与动机题

- 为什么想做产品经理？（转岗者必考，结构见 experience-mining.md 第 3 节）
- 你之前做 XX 的，为什么转产品？
- 为什么离职？（向前看结构，见潜台词表）
- 你的职业规划是什么？
- 为什么选我们公司？
- 你觉得 PM 需要哪些能力？（用五维能力模型作答，见 stakeholders-career.md 第 4 节）
- 如果被录取了，你前 90 天怎么开展工作？（高分结构：了解→小胜→体系）
- 你是倾听者还是演讲者？（无标准答案，考自我认知一致性）
- 你还有什么要问我的？（见 prep 第 7 节）

## 九、技术与 AI 题（海外岗 + AI 产品岗）

- 向 12 岁孩子解释 DNS（技术沟通题：考翻译能力不考深度）
- 讲一个你做过的技术取舍
- 设计 Instagram 首页 Feed 的架构（技术型 PM 岗）
- 如何定义一个 AI 功能的成功？（ai-products.md 第 3 节 evals 视角作答）
- 如何发布一个新的大模型产品？（灰度 + evals + 安全护栏）
- 产品速度与 AI 安全约束怎么平衡？
- 如何看待 AI 安全？（考成熟度：能讲出具体机制者稀少）

## 出题使用说明（给模拟面试官）

1. 一场标准模拟 = 1 道经历题 + 1 道该岗位主考题型 + 1 道次考题型 + 反问环节，40-60 分钟
2. 把题库原题**本地化到目标公司**：面字节把"改进 Instagram"换成"改进抖音"；面 B 端公司把 C 端设计题换成工作方法题
3. 校招权重：设计题 > 认知题 > 估算题 > 经历题；社招权重：经历深挖 > 工作方法 > 设计题；海外：按轮次专项练
4. 同一道题可以反复练——第二遍练的是"结构内化后的自然表达"，背诵感本身就是扣分项
