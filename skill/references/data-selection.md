# 数据选型地图（看什么数）——目的 × 阶段 × 业态

第一性原理：**数据是带着问题去查的，不是收集来看的。** 先说清要回答什么问题，再决定看什么数；没有目的的取数是浪费，没有目的的看板是数字坟场。本文件是"我现在要干 X，该看什么数"的直查地图；data-system.md 的 OSM 是从目标正式推导指标体系的方法——日常先查地图，搭体系时用 OSM 校验推导链；选出来的候选指标再用 metrics.md §0 的五问过滤；单个指标的精确口径、用途与陷阱查 metric-library.md（27 域指标全集字典）。

选型三轴：**目的**（要回答什么问题）→ **阶段**（同一目的在不同阶段看的数不同）→ **业态**（每类生意有自己的特征指标集）。

## 一、按目的选数据（九个高频目的）

每条 = 要回答的问题 → 首选数据 → 常见误用。

**1. 验证价值 / 找 PMF** —— "有没有人真的离不开它？"
看：留存曲线形态（衰减后是否走平、平台期高度）；自然增长占比（非买量新增的比例）；高频使用群的规模和他们的共同行为；"如果不能再用你会多失望"调研中"非常失望"的占比（40% 是常用参考线）。
误用：拿注册量、下载量、融资新闻当验证——规模指标在这个目的下全部无效。

**2. 诊断增长** —— "增长卡在哪一环？"
看：先把增长写成公式（DAU = 新增 × 留存曲线积分；新增 = 渠道量 × 转化），逐因子看趋势定位瓶颈；分渠道的留存与 LTV（渠道质量 > 渠道数量，买来即走的量是负资产）；漏斗分步转化找最大掉落点；增长循环的回路效率（老用户带来新用户的系数）。
误用：只看大盘新增总量——渠道结构恶化会被总量掩盖。

**3. 提升留存 / 活跃** —— "谁留下了，为什么？"
看：分群留存曲线（新老、渠道、行为群分开画，全局均值会撒谎）；激活行为与留存的相关性（找 aha 行为——注意这只是相关，选择效应大坑，要用实验确认因果再压资源）；使用频次分布（看分布不看人均，双峰结构下人均是幻觉）；流失用户流失前 7-14 天的行为信号（频次下降、核心动作消失）。
误用："用过 X 功能的用户留存高，所以推 X"——活跃的人才碰得到 X，先问因果。

**4. 变现 / 商业化** —— "钱从哪来、可持续吗？"
看：付费转化漏斗（触达定价点 → 试用 → 付费 → 续费/复购）；ARPU / ARPPU 与付费率的乘法关系（提价还是扩付费面，两条路的数据完全不同）；LTV/CAC（LTV 用毛利算，不用流水）；收入结构集中度（大客户/大 R 依赖度）；折扣与补贴的侵蚀率。
误用：只看收入绝对值——结构恶化（靠折扣冲量、靠头部撑）在总数里看不见。

**5. 评估新功能** —— "它带来增量了吗？"
看：渗透漏斗（曝光 → 点击 → 首次使用 → 重复使用，逐层看在哪断）；对核心指标的增量（有对照才叫增量：AB 或 holdout）；护栏（是否挤占其他功能、拉高负反馈/卸载）；重复使用率（首次是好奇，第二次才是价值）。
误用：拿"使用者留存高于未使用者"当结论（选择效应）；拿使用量当成功（可能只是入口位置好）。

**6. 定位异动** —— "哪里变了、为什么？"
看：按 pm-thinking-os.md 的归因阶梯走——口径与埋点变更记录 → 大盘 × 渗透率拆解 → 变更日志（发版/运营/策略）→ 新老/渠道/版本/地区切分 → 机制假设对应的数据。
误用：跳过数据真实性检查直接开脑暴（异动一半是数据问题）。

**7. 理解用户** —— "他们是谁、在什么场景、为什么？"
看：行为分群（按频次 × 深度切，不按年龄性别切——人口属性分群是给广告投放用的，不是给产品决策用的）；真实使用路径 vs 设计路径的偏差（用户用出来的路径藏着真实需求）；配套定性（访谈/工单/评价）——定量回答"多大、在哪"，定性回答"为什么"，谁也替代不了谁。
误用：用人口画像替代行为画像；访谈样本里只有重度用户。

**8. 向上汇报 / 对外讲故事** —— "业务健康且在变好吗？"
看：规模 + 增速 + 质量三件套：北极星及同比环比、新 cohort 质量趋势（新来的用户是不是越来越差）、单位经济。一页纸一个主指标，其余全是支撑。
误用：报喜式挑指标——挑出来的数会被一个口径追问击穿，信用比数字贵。

**9. 日常监控（看板）** —— "今天有没有事？"
看：北极星 + 输入指标 + 护栏指标的分层看板（搭法见 data-system.md）；异动报警阈值（周同比 ± 历史波动带）；每周一次分维度巡检（大盘平稳不代表结构平稳）。
误用：把所有能算的数都放上看板——看板上每多一个没人行动的数，重要的数就被稀释一分。

## 二、按阶段修正（同一目的，不同阶段的数不同）

- **冷启动 / 验证期（0→1）**：样本小到统计无意义，**定性权重 > 定量**。只盯两个数：激活率（第一次使用就摸到核心价值的比例）和早期留存曲线走不走平。别搭复杂看板、别定北极星——先找到 aha 行为再说。此阶段看规模指标是自我麻醉。
- **成长期（1→10）**：看增长的**效率与质量**：分渠道 LTV/CAC、新 cohort 留存是否劣化（规模扩大人群稀释是常态，劣化速度决定天花板）、增长循环哪一环是瓶颈。
- **成熟期**：看**结构与纵深**：细分人群渗透率还有多少空间、变现深度（ARPU 提升路径）、成本效率、护城河的代理指标（迁移成本、网络密度、心智占有——搜索品牌词量是个不错的代理）。警惕大盘平稳掩盖结构恶化。
- **衰退 / 转型期**：看**流向与残值**：流失用户去了哪、为什么（竞品还是需求消失，答案决定挣扎还是转身）；存量的变现残值；第二曲线业务的先导指标单独建看板，别和主业混在一起考核。

## 三、按业态选特征指标集

每类给：北极星候选 ｜ 特征指标 ｜ 生死线。（水位区间是行业粗粒度手感，随品类年份漂移，你的品类要单看。）

- **工具**：北极星候选 = 核心任务完成次数/完成用户数 ｜ 特征：激活率、任务成功率、完成耗时 ｜ 生死线：次留（25-40% 是能打的水位）；变现看免费转付费（2-5% 算健康）。
- **内容 / 社区**：**双侧都要看，供给先于消费死**。消费侧：人均时长、互动率、次留（35-50%）；生产侧：创作者渗透率（发过内容的用户占比）、发布留存（发过的人还会不会再发）、新内容被消费率（发出来没人看，创作者会走）；分发侧：消费集中度（头部内容占比——集中度就是平台的基尼系数）。
- **社交 / IM**：关系链密度（人均双向关系数）、DAU/MAU（50%+ 是这类产品的常态）、消息回复率与回复时延；网络价值看密度不看总量（同城/同校/同司的浓度才产生价值）。
- **电商 / 交易**：GMV = UV × 转化率 × 客单价，逐因子归因；复购率与购买频次（首单是买来的，复购才是产品力）；履约体验（时效、破损、退货率）；UE（毛利 − 履约 − 获客摊销，单均为负时 GMV 增长 = 加速失血）。生死线：复购与 UE。
- **双边平台 / 市场**：匹配效率是命根——供给利用率（司机接单率/房源出租率）与需求满足率（叫到车的比例、等待时长）成对看，只看一侧会把另一侧烧死；两侧留存分开画曲线；跨边效应强度（供给密度增加对需求转化的弹性）——它决定补贴该打在哪一侧。
- **SaaS / B 端**：MRR/ARR 与 NRR（净收入留存 >100% 意味着不拉新客也在增长，是最硬的产品力证据）；金额流失 vs 客户数流失分开看（丢 10 个小客户和丢 1 个大客户是两种病）；**席位使用率（买了 ≠ 在用，续约前 90 天的使用率是最好的续约预测器）**；CAC 回收期（12-18 个月内算健康）。
- **游戏**：次留/7 留/30 留（次留 30-50%，D30 能站上 15% 已优秀——区间随品类漂移大）；付费率 × ARPPU 与大 R 集中度（收入结构决定运营策略）；内容消耗速度 vs 产能（用户玩得比你做得快，就是流失倒计时）。
- **AI 产品**：通用指标之外——任务成功率/采纳率（AI 输出被接受或采用的比例）、修正率（用户改了多少才能用）、重试与放弃率（信任的代理指标）、单任务推理成本（毛利被算力吃掉是这类产品独有的 UE 风险）。评估体系细节见 ai-products.md。

## 四、数据形态的选择（不只是选指标）

"看什么数据"还包括选数据形态，各回答不同层的问题：
- **行为埋点**：回答"用户做了什么"。只埋和决策挂钩的（治理纪律见 data-system.md）。
- **业务库表**（订单/交易/账务）：口径最硬的事实数据。和钱有关的结论优先用库表，不用埋点——埋点会丢，账不会。
- **定性数据**（访谈/工单/应用商店评价/NPS 追问）：回答"为什么"。定量定位、定性归因，谁也替代不了谁。
- **实验数据**：回答"是不是它导致的"。上面所有形态都只能给相关，因果只有对照能给。
- **外部数据**（三方报告/榜单/财报/搜索指数）：回答"行业水位与相对位置"。校准预期用，别拿来当内部决策的精确依据。

选择顺序：先判断问题是"多大、在哪"（定量）、"为什么"（定性）、还是"是不是它导致的"（实验），再去对应形态取数——顺序反了就会出现"访谈了 8 个用户得出转化率结论"这类事故。

## 五、使用纪律

1. **不改变行动的数据不取**：取数前自问"结果是 X 我做什么、是 Y 我做什么"——两个答案一样，这个数不用看。
2. **每个目的主看 3-5 个数**：多了等于没有重点；看板加数要有"减法栏"。
3. **候选指标过五问再上岗**（metrics.md §0）：可行动、领先/滞后、比率优先、防操纵、非虚荣。
4. **水位数字永远带免责**：报区间 + "行业大致水位" + "你的品类单看"（弹药与更多区间见 industry-sense.md）。
