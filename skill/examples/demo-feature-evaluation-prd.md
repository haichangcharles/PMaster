# "AI 一对一口语陪练"功能评估 + 简版 PRD

K12 在线教育 App（MAU 300 万）· 评估人：PM · 状态：草稿（待评审）

---

## 一、结论/建议（先行）

**建议：值得做，但不按老板给的方式直接做。** 分两步走：

1. **不做"泛口语自由聊天陪练"**——那是把 AI 能力当需求，K12 场景下是维生素不是止痛药。
2. **做"锚定中高考英语听说考试的 AI 陪练"**（听说考试模拟 + 逐句纠音 + 考前冲刺），以 4-6 周 MVP 灰度验证，预算控制在 3 人团队一个迭代周期内。

**推翻条件（强观点，弱执念）**：
- 假门测试入口点击率 < 3%（基线：站内新功能入口点击率均值），说明兴趣假设不成立 → 停止；
- MVP 灰度用户的次周功能留存 < 25%，且完课/完练率 < 40%，说明是新奇效应而非真需求 → 转向或下线；
- 单次 15 分钟会话成本无法压到 ¥1 以下（毛利 < 50%）→ 重新设计（小模型分流/限额）再上，不带病放量。

**为什么不是照单全收，也不是反对**：老板方案背后的目标需要还原。判断其真实目标是三者之一：① 给产品加一个 AI 心智卖点（竞争防御）；② 找新的付费增长点；③ 提升留存。下文按"三个目标都要能兜住"的标准评估——结论是锚定应试的口语陪练三个目标都能沾，泛聊天陪练只能沾第一个。

---

## 二、问题与背景（我们到底在为谁解决什么问题）

### 1. 还原问题（不从方案出发）

"AI 口语陪练"是方案。背后的用户问题用 JTBD 陈述：

> **当**我家孩子要参加中高考英语听说机考（北京/上海/广州/深圳等地已计入总分，多省市在跟进），**我想要**孩子有便宜、随时可用、不怕丢脸的开口练习方式，**以便**听说部分不丢分。

三层 job 拆解：
- **功能层**：练发音、练听说题型、拿分；
- **情感层**：孩子怕在真人面前开口出丑（AI 无评判压力是结构性优势）；家长要"我为孩子做了安排"的安心感；
- **社会层**：家长间"你家孩子用什么练口语"的谈资。**付费能力藏在情感层和社会层**——纯功能层（跟读打分）早已被免费工具满足。

### 2. 需求真伪四问

| 过滤问 | 判断 |
|---|---|
| 频率 × 强度 | 对听说考试省市的初三/高三家庭：**中频刚需**（考前 3-6 个月高频）；对非考试省市低年级：低频非刚需（本次放弃） |
| 谁付钱/谁使用/谁决策 | **家长付钱和决策，孩子使用**——典型 K12 分离结构。卖点必须对家长讲"提分/考试"，体验必须对孩子讲"不尴尬/有意思"。泛聊天陪练对家长无法回答"这对考试有什么用"，这是它的死穴 |
| 现有替代 | 真人外教 1v1（¥100-200/节，贵且约课麻烦）；跟读打分类免费工具（无对话能力）；流利说/多邻国（成人向/兴趣向，非 K12 应试）；有道 Hi Echo、讯飞、豆包类 AI 口语（已验证"AI 口语对话"技术假设，但多数未深耕 K12 听说考试题型）。**竞品验证了假设 ≠ 竞品占住了我们的场景**——我们的差异化在"存量 3 百万 K12 用户 + 应试场景绑定"，这是通用 AI 口语 App 结构性做不了的角度 |
| 止痛药还是维生素 | 锚定听说考试 = **止痛药**（考试倒计时就是天然的紧迫感）；泛口语聊天 = 维生素（需长期习惯养成，K12 用户时间被作业挤压，养成概率低） |

**痛点强度信号**（待访谈验证，当前为桌面判断）：家长已在为真人外教/听说考试冲刺班付费（信号强度第 1 级）；学校老师用微信群人肉布置跟读作业（第 2 级土办法信号）。这两条若在访谈中证实，需求成立度高。

### 3. 机会评估六问（Cagan 精简版）

1. **解决什么问题**：K12 学生缺少低成本、无压力、贴考纲的口语开口练习机会。
2. **为谁解决**：Beachhead 人群 = 听说机考省市的初二至初三学生及其家长（先窄后宽，不是"所有学英语的孩子"）。
3. **机会多大**：站内测算——300 万 MAU 中假设 30-40% 位于听说机考省市（≈100 万，置信度中，需用注册地数据核实），其中初中段假设 40%（≈40 万目标池）。渗透 10% 即 4 万 MAU 的高价值活跃场景。区间：目标池 25-55 万。
4. **怎么衡量成功**：见 PRD 指标节。
5. **为什么是我们/为什么是现在**：我们有 K12 用户存量和信任（获客成本≈0，通用 AI App 要花钱买这些用户）；LLM+ASR+TTS 成本 2024-2025 年下降一个数量级，实时语音对话延迟进入可用区间；听说机考省市扩围是政策时间窗。
6. **不做会怎样**：字节（豆包/河马爱学）、网易有道、讯飞都在向 K12 口语渗透。口语练习是高频打开场景，被竞品占住会反向侵蚀我们的使用时长。不做的机会成本 > 做错的试错成本（本决策是 Type 2 可逆决策，应快速小成本验证）。

### 4. 用户价值公式检验（俞军）

用户价值 = 新体验 − 旧体验 − 切换成本。
- vs 真人外教：价格约 1/10~1/20、随时可练、无尴尬 → **10x 级改善**（满足 10x rule）；
- vs 免费跟读工具：多轮对话 + 考试题型模拟 + 个性化纠错 → 明显但需做实"贴考纲"才守得住；
- 切换成本：用户已在我们 App 内，≈0。这是本机会最大的结构性优势。

## 三、方案与理由（含备选对比）

### 方案对比

| 方案 | 收益 | 成本 | 风险 | 可逆性 |
|---|---|---|---|---|
| A. 泛口语自由聊天陪练（老板原案） | AI 卖点、PR 好看 | 中（通用对话质量要求高） | 对家长无提分叙事，付费转化差；新奇效应后留存崩 | 高（可下线） |
| B. **锚定听说考试的 AI 陪练（推荐）** | 三目标兼顾：卖点+付费+留存；差异化竞品难抄（题库+考纲是我们的领域深度） | 中（需题型内容建设 + evals） | 依赖考试省市用户占比假设 | 高（灰度可控） |
| C. 接第三方白标 AI 口语 SDK | 最快上线 | 低前期/高长期（抽成+数据不回流） | 无数据飞轮、无护城河，等于替别人养场景 | 中 |
| D. 不做，观察竞品 | 零成本 | 机会成本 | 场景被占，时长流失 | — |

**选 B 的理由**：AI 产品的护城河不在模型（大家都调 API），在①工作流嵌入深度、②专有数据回流、③场景独占。方案 B 三条全占：嵌入我们已有的学-练-测流程；学生的发音错误/纠错数据回流改进评分与推荐；用存量用户先占住"App 内练口语"心智。方案 C 把 ② 拱手让人，方案 A 三条都弱。

**产品形态选择**（AI 形态决策树）：**Copilot 式结构化对话**，不是全自由 Agent。自主性 ≤ 可靠性 × 错误可容忍度——面向未成年人，错误可容忍度低，所以用"预设题型脚本框架内的受限对话"（AI 在题型轨道上引导，自由发挥限定在安全话题池），而非开放闲聊。这同时解决了内容安全和成本控制。

**混合架构**：发音评分用成熟 ASR 打分引擎（确定性、便宜），LLM 只做对话生成与语法纠错讲解——能用规则和小模型解决的不用大模型。

## 四、数据/证据

- **政策面**：中高考英语听说机考已在北上广深等地计入总分且多省市推进中（时间窗证据）。
- **竞品面**：有道 Hi Echo、流利说、讯飞、豆包等已验证"AI 口语对话"的技术可行性与用户接受度（竞品验证了假设，这是有价值的输入；"竞品有"本身不构成理由）。
- **站内数据（上线评审前必须补齐的三条基线）**：① 用户注册地/年级分布 → 校准目标池 25-55 万的估算；② 现有英语类内容的渗透与完成率 → 判断英语学习意愿基线；③ 站内搜索/客服工单中"口语/听说/发音"相关诉求量 → 痛点响度佐证（注意响度 ≠ 重要度，需与行为数据交叉）。
- **待补定性证据**：5-8 组听说机考省市初中家庭访谈（Mom Test 纪律：只问"上次孩子练口语是怎么练的、花了多少钱"，不问"你会不会用 AI 陪练"）。
- **成本测算（关键假设，置信度中）**：单次 15 分钟会话 ≈ ASR + LLM（约 8-12k tokens，走中档模型+缓存）+ TTS，估算 **¥0.3-0.8/次**，重度用户月 20 次 → 月成本 ¥6-16/人。对照定价假设（会员增值包 ¥30-50/月）毛利可 > 50%，但**模型选型一变就要重算**，上线前财务模型必须实测校准。

## 五、风险与应对

| 风险 | 象限 | 应对 |
|---|---|---|
| **合规：学科类培训监管（双减）** | 高影响中概率 | 上线前法务专项评审：功能定位为"App 内自学工具"而非"培训服务"，不做真人授课、不按课时售卖；这是不可逆风险，按 Type 1 决策处理——慢而慎，法务不过审就不上线 |
| **未成年人个人信息（PIPL）**：儿童语音是敏感个人信息 | 高影响高概率 | 14 岁以下监护人同意流程；语音数据最小化采集、明示用途；用户数据用于模型改进必须显式同意且可关闭 |
| **AI 输出不当内容（面向未成年人零容忍）** | 高影响低概率 | 受限话题池 + 输出过滤 + 对抗性测试（越狱/诱导样本进 eval 集）；生成内容按法规标识 AI 身份 |
| **新奇效应假繁荣** | 高概率中影响 | 不看首周数据做放量决策；以 4 周留存分层为准；灰度每级停留 ≥ 48h |
| **推理成本失控** | 中概率中影响 | 单位会话成本进常规监控看板；免费额度 + 会员限额；简单请求路由小模型 |
| **发音评分不准伤信任**（家长按分数判断价值） | 中概率高影响 | 评分引擎用人工标注集校准后再上；分数展示区间化+进步趋势化，弱化单次绝对分 |
| **中台/算法资源排期延误** | 高概率中影响 | 立项即锁定语音中台排期与 SLA；Plan B = 第三方 ASR API 过渡 |

# 简版 PRD：AI 听说陪练（内部代号"开口"）

版本 0.1 · 作者：PM · 评审人：技术负责人/设计/法务/数据 · 状态：草稿
（评审前已完成与技术负责人、交互的一对一预沟通——会上不出现第一次听说方案的关键角色）

## 1. 背景与问题（为什么做）

- **问题陈述**：听说机考省市的初中生（App 内目标池估 25-55 万）缺少低成本、随时可用、不怕出丑的口语开口练习方式；真人外教贵且约课难，免费跟读工具无对话与题型能力。损失 = 听说分丢分 + 家长为低效替代品超额付费。
- **证据**（上线评审版需各补一条实数）：数据——站内"口语/听说"相关搜索与工单量 N 条/月；用户原声——访谈中家长典型原话（占位，访谈后回填）。
- **为什么是现在**：听说机考省市扩围（政策窗）+ 语音大模型成本下降一个数量级（技术窗）+ 竞品尚未占住 K12 应试口语心智（竞争窗）。

## 2. 目标与成功指标

- **目标**：
  - 用户视角：让目标学生每周至少完成 2 次、每次 ≥ 10 分钟的有效开口练习，听说模拟成绩可见提升。
  - 业务视角：验证 AI 陪练作为会员增值付费点的转化能力，并提升目标人群周活跃。
- **成功指标**：
  - 北极星贡献：目标人群"周有效学习时长"提升（本功能贡献 ≥ +8%，灰度组 vs 对照组）；
  - 功能级：功能周留存（W4 ≥ 25%）；单次会话完成率 ≥ 60%；（付费版上线后）增值包转化率 ≥ 3%；
  - 领先指标驱动日常：首次会话完成"完整 1 轮题型练习"的比例（激活代理，季度回测其与留存相关性）。
- **护栏指标**：App 整体崩溃率不升；客诉率（尤其家长投诉内容安全类 = 0 容忍）；单次会话成本 ≤ ¥0.8；发音评分与人工标注一致率 ≥ 85% 不恶化。
- **Non-goals（明确不做）**：
  1. 不做开放式自由闲聊（内容安全与成本不可控，且对提分叙事无贡献）；
  2. 不做真人外教连线/真人点评（触碰双减培训红线）；
  3. 不做小学低年级与非听说机考省市的定制内容（Beachhead 之外，V2 再议）；
  4. 不做语文/其他学科口语迁移（先在英语打透）。

## 3. 用户与场景

- **目标用户**：听说机考省市初二-初三学生（使用者）+ 其家长（付费决策者）。
- 用户故事：
  - P0：作为初三学生，我想要模拟听说考试全流程并逐题得到发音与答法反馈，以便考前知道自己哪里丢分。
  - P0：作为学生，我想要跟 AI 就课本话题进行有引导的对话练习且说错不被嘲笑，以便敢开口、越说越顺。
  - P1：作为家长，我想要每周收到孩子的练习报告（时长、进步曲线、薄弱项），以便确认花的钱有效果。
  - P2：作为老师（若有 B 端入口），我想要给班级布置口语练习任务，以便替代微信群人肉收跟读音频。

## 4. 方案描述

- **核心流程（P0）**：选择练习模式（考试模拟/话题对话）→ 音频权限与设备检测 → 结构化对话练习（AI 引导，逐句 ASR 评分）→ 结束页（得分区间 + 3 条具体改进点 + 明日推荐练习）→ 家长端周报。
- **形态与架构**：Copilot 式受限对话；ASR 打分引擎做发音评测（确定性），LLM 做对话生成与讲解；简单跟读请求不走大模型。流式 TTS 保证首响应 < 1.5s 体感即时。
- **AI UX 关键设计**：冷启动不给空输入框（提供题型入口与示例）；AI 明示身份与能力边界；评分展示区间与趋势而非绝对分；每条反馈带"点错了/没听懂"轻量纠错入口（纠错数据回流 eval 集）。
- **异常与边界**：麦克风权限拒绝、嘈杂环境识别失败（提示重录并降噪引导）、方言/口音重（不打击性话术）、长时间静默（引导或暂停计费）、模型超时降级（切本地跟读模式）、未成年人触发敏感话题（终止话轮 + 兜底话术 + 记录进 eval）、新老版本兼容（老版本隐藏入口）。
- **Evals 计划（AI 功能的 PRD 必备节，rubric 由 PM 亲自写）**：
  - 上线前建 150-200 条评测集：典型题型 × 边缘口音 × 对抗输入（诱导闲聊、越狱、敏感话题）；
  - 三层：程序化断言（格式/禁词/长度）→ LLM-as-judge 按 rubric 打分（judge 与被评模型不同，与人工标注一致率 > 85% 才启用）→ 每周人工抽检 30 条真实会话；
  - 核心指标：对话符合题型轨道率、纠错讲解正确率、不当内容率（目标 0）、拒答正确率、延迟 P95、单次成本；每次 prompt/模型变更跑全量回归。
- **埋点需求**：入口曝光/点击、会话开始/完成/中断（含中断节点）、每轮延迟与成本、评分分布、纠错反馈点击、家长报告打开率——上线首日即须可查。

## 5. 依赖与影响面

- 语音中台（ASR/TTS）排期与 SLA（头号延期风险，需 Plan B：第三方 API）；LLM 网关配额；会员系统（付费版）；家长端消息通道；法务合规评审（阻塞项）。
- 对现有功能影响：练习时长可能分流现有视频课时长（预期内的良性替代，纳入北极星整体核算）。

## 6. 发布计划

- 灰度阶梯：内部 dogfood（1 周）→ 白名单种子 500 人（含访谈家庭）→ 1% → 5% → 20% → 50% → 100%；每级停留 ≥ 48h。
- 量化闸门：继续 = 完成率 ≥ 55% 且客诉 0 且成本达标；暂停 = 完成率 < 40% 或评分投诉集中；回滚 = 出现任一内容安全事故（feature flag 秒级关闭，不发版）。
- 物料：客服 FAQ 与话术、家长端功能说明、新手引导；数据看板在灰度前建好。
- **Post-launch review**：上线后第 4 周，对照本 PRD 预测值复盘，决定加码/迭代/接受/下线。

## 7. 里程碑与开放问题

- 里程碑：W1-2 访谈+假门 → W3 立项过评审 → W4-8 MVP 开发（3 人：1 客户端 1 后端 1 算法对接）→ W9 灰度 → W12 复盘决策。
- 开放问题：
  1. 付费形态：并入现有会员 vs 独立增值包？（待假门预约页 A/B 定价意愿数据）
  2. 听说机考题型的省市差异内容成本多大？先做北京/广东两套还是通用题型？
  3. 14 岁以下监护人同意的产品流程走注册链路改造还是功能内弹窗？（法务周内给结论）
  4. 语音数据保留时长与用途边界（合规与数据飞轮的平衡，法务+算法联合定）。
